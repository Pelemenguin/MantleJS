# PageTypeRegistryEventJS

A event for page type creation.

> **`create(string id)`**
> 
> Create a new page type.
> 
> **Parameters**:
> - `id`: A string object. Namespace `kubejs` will be automatically added if no namespace is specified.
>
> **Returns**:
> - A [PageTypeBuilder](../book/pagetype/PageTypeBuilder.md) object.
